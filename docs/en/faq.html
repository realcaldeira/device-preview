FAQ & common issues

Updated for 1.6.1 · Chrome/Edge 116+

Blank site / “refused to connect”

Some sites use JavaScript frame-busting (if (top !== self)) or strict SameSite cookies that break inside iframes. The extension strips X-Frame-Options and CSP only on the preview tab — that covers most cases, not all. Try another domain or a public page without login.

Login / payment fails inside the mockup

Expected for many OAuth flows and strict cookies. Use the preview for layout and performance; validate auth on a real device or DevTools Device Mode when needed.

The site still “feels desktop” in CSS

Stylesheet rules like @media (hover: hover) / (pointer: fine) are still evaluated by Chrome as desktop. JavaScript matchMedia and the User-Agent are overridden; the Blink CSS engine alone is not.

Why request access to all sites?

To apply the device User-Agent and embed any URL in the preview iframe. No other tabs are affected. Nothing is sent to servers — see the privacy policy.

Shortcuts & local retention

  • Alt+Shift+P — reopen the last device and URL.
  • Favorites, presets, theme and history stay only in chrome.storage.local.

Cropped PNG capture

Capture uses the visible tab. If the mockup does not fit, the extension auto-adjusts zoom before saving. Maximize the window if it still fails.
