# Docs (GitHub Pages)

Publique com **Settings → Pages → Deploy from branch → `/docs`**.

URLs esperadas após o deploy:

- Landing PT: https://realcaldeira.github.io/device-preview/
- Landing EN: https://realcaldeira.github.io/device-preview/en/
- FAQ PT/EN: `faq.html` · `en/faq.html`
- Uninstall: `uninstall.html` (redireciona para EN se o navegador não for PT)
- Privacy: https://realcaldeira.github.io/device-preview/privacy-policy.html

A extensão segue o idioma do Chrome (`_locales`: en, pt_BR, es, fr, de).

Rascunhos de divulgação: [`content/`](content/).
