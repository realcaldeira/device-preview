## Description détaillée

```
Des tests responsive au-delà de Chrome DevTools.

Simulateur Mobile ouvre n’importe quel site dans un cadre photoréaliste (encoche, Dynamic Island, punch-hole, PC portable et TV) avec un User-Agent réel, un vrai tactile, un clavier virtuel qui tape vraiment, et un compteur FPS (live + 1 % low).

POUR QUI
• Développeurs et QA qui valident les layouts
• Designers qui ont besoin de mockups réalistes
• Quiconque compare les perfs sur de vrais viewports

POINTS FORTS
• 50 appareils avec viewport, DPR et User-Agent réels
• Cadres 9-slice (iPhone, Android, iPad, MacBook, Smart TV)
• Tactile réel sur téléphone/tablette
• Clavier virtuel iOS/Android
• Capture PNG à la résolution physique
• Favoris, presets et historique récent
• Zéro collecte de données

COMMENT FAIRE
1. Ouvrez le site à tester
2. Cliquez sur l’icône (ou Alt+Shift+P pour rouvrir le dernier)
3. Choisissez un appareil dans le panneau latéral
4. Tournez, capturez, mesurez les FPS ou changez d’appareil

POURQUOI CES PERMISSIONS
L’extension modifie l’User-Agent et retire X-Frame-Options/CSP uniquement sur l’onglet d’aperçu. Aucune URL ni contenu n’est envoyé à des serveurs.

Si cela vous fait gagner du temps, un avis ★★★★★ aide d’autres développeurs à le trouver.
```
