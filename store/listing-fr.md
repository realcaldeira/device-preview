## Description détaillée

Seules les deux premières lignes s'affichent avant « Lire la suite ».

```
Des tests responsive au-delà de Chrome DevTools : 50 appareils réels,
User-Agent réel et vrai tactile, dans un cadre photoréaliste.

Simulateur Mobile ouvre n'importe quel site dans un cadre avec encoche,
Dynamic Island, punch-hole, châssis de PC portable ou de TV, envoie le
User-Agent réel de l'appareil, défile au doigt avec inertie, fait
monter un clavier virtuel qui tape vraiment et mesure les FPS
(live + 1 % low).

POUR QUI
• Développeurs et QA qui valident les layouts
• Designers qui ont besoin de mockups réalistes
• Quiconque compare les perfs sur de vrais viewports

POINTS FORTS
• 50 appareils avec viewport, DPR et User-Agent réels
• Cadres 9-slice (iPhone, Android, iPad, MacBook, Smart TV)
• Tactile réel sur téléphone/tablette (pointer: coarse, inertie)
• Clavier virtuel iOS/Android (numérique et symboles)
• Barre Chrome/Safari dans le mockup
• Capture PNG à la résolution physique de l'appareil
• Favoris, presets de workflow et historique récent
• Zéro collecte de données — tout reste dans votre navigateur

COMMENT FAIRE
1. Ouvrez le site à tester
2. Cliquez sur l'icône (ou Alt+Shift+P pour rouvrir le dernier)
3. Choisissez un appareil dans le panneau latéral
4. Tournez, capturez, mesurez les FPS ou changez d'appareil

POURQUOI CES PERMISSIONS
L'extension modifie l'User-Agent et retire X-Frame-Options/CSP
uniquement sur l'onglet d'aperçu, pour que le site puisse s'afficher
dans le mockup. Aucun autre onglet n'est touché. Aucune URL ni contenu
n'est envoyé à des serveurs.

Gratuit, sans compte et sans télémétrie. Code et confidentialité :
https://realcaldeira.github.io/device-preview
```
