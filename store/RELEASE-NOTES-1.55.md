# Notas de versão — 1.55

## Português

```
• Novo: botão "Ajustar ao conteúdo" para celulares e tablets — renderiza o
  site na largura de desktop e reduz a escala para caber na tela do aparelho,
  como o "Site para computador" do Chrome Android; páginas que não têm layout
  para telas estreitas deixam de aparecer cortadas
```

## English

```
• New: "Fit content" button for phones and tablets — lays the site out at
  desktop width and scales it down to the device screen, like Chrome Android's
  "Desktop site"; pages with no layout for narrow screens no longer look
  clipped
```
