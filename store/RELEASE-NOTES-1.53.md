# Notas de versão — 1.53

## Português

```
• Correção: em abas com id alto as regras de rede não eram aplicadas e o site
  continuava recebendo o User-Agent de desktop
• Correção: o botão Voltar da prévia podia fechar a prévia e devolver a aba ao
  site original em vez de voltar dentro do site
• Correção: teclado virtual, rótulo "Nova aba" e avisos do medidor de FPS agora
  seguem o idioma do Chrome
• Correção: endereços que não são http(s) não deixam mais a prévia em branco
• Correção: falhas do painel agora dizem qual pedido falhou e em qual versão
```

## English

```
• Fix: on tabs with high ids the network rules were not applied and the site
  kept receiving the desktop User-Agent
• Fix: the preview Back button could close the preview and return the tab to the
  original site instead of going back within the site
• Fix: virtual keyboard, the "New tab" label and FPS meter warnings now follow
  the Chrome language
• Fix: non-http(s) addresses no longer leave the preview blank
• Fix: panel failures now name the failing request and the running version
```
